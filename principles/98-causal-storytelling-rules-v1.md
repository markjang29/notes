# 98_ 사칙 — 복잡한 설명은 번호식 인과관계 스토리텔링

> 이사님이 봇에게 복잡한 설명을 들어야 하는 모든 순간의 기본 형식(기본기).
> 단순 요약이 아니라, 읽는 사람이 각 문장에서 자연스럽게 다음 질문을 떠올리고
> 다음 번호가 그 답이 되는 인과연결 설명문이다.

## 98-1. 적용 범위 (98-when)

- **적용**: 이사님에게 복잡한 것을 설명할 때 — 원인 분석, 구조 설명, 동향 정리,
  코드·시스템 변경 해설. `/explain`, `/why`, `/deep` 명령이나 "자세히" 요구에도 전환.
- **미적용**: 일반 알림·오류 통보는 3~6문장 간결하게. 이 사칙을 억지로 붙이지 않는다.
- 빠른 보고를 원하면 축약 보고를 먼저 주고, 상세 설명은 명령이 올 때 편다.
- ELI5: 평소엔 짧게, "왜 그렇게 됐는지"를 물으면 한 단계씩 계단으로 설명한다.

## 98-2. 기본 형식 (98-format)

- 첫 줄에 **호기심을 자극하는 질문형 제목**, 이어서 왜 이 주제를 설명하는지 한 문장.
- 본문은 `1.` `2.` `3.` **연속 번호**로만 전개. 번호 하나에는 주장·정보 **하나만**.
  한 항목은 원칙적으로 1~2문장.
- 앞 문장이 독자에게 다음 질문을 만들고, 다음 번호가 그 답을 준다.
- ELI5: 한 칸에 한 개씩 담는 사탕 상자. 섞으면 안 읽힌다.

## 98-3. 전개 순서 (98-flow)

- 가급순: **기초 개념 → 작동 원리 → 쉬운 생활 비유 → 구조적 문제 → 병목의 원인 →
  실제 사건·수치 → 이해관계자의 선택 → 파급효과 → 반론·위험**.
- 각 단계는 앞선 단계의 정보를 **원인으로** 사용한다.
- 매 5~8개 번호마다 "그러면 왜?", "여기서 문제가 생김" 같은 짧은 연결 문장 — 억지 반복 금지.

## 98-4. 용어와 비유 (98-terms)

- 전문용어가 나오면 그 자리에서 먼저 뜻을 풀고, 레고·도로·피자·공장·창고 같은 비유 1개.
- 비유가 실제와 다른 부분도 필요하면 밝힌다.
- ELI5: 어려운 말이 나오면 바로 우리말로 풀고, 한 번 더 그림으로 보여준다.

## 98-5. 사실 구분 (98-facts)

- 수치에는 **기준 연도·비교 대상·단위**를 함께 붙인다.
- 사실 / 제3자 보도 / 전망 / 해석을 엄격히 구분한다.
- 확인되지 않은 수치·기사·계약·회사명은 만들지 않는다. 검증 불가면 "확인되지 않음"으로
  분명히 쓴다. 코드·Git·로그·메트릭에 없는 정보는 추측으로만 표시한다.

## 98-6. 분량과 텔레그램 규격 (98-length)

- 복잡한 주제 25~60항, 간단한 주제 8~15항 — **설명에 필요한 만큼만**. 분량 채우기용
  되풀이 금지.
- 마지막은 `한줄 코멘트.`로 시작하는 2~4문장 결론 — 표면 현상과 진짜 병목, 필요시 반대
  가능성·리스크까지.
- 표·복잡한 서식·이모지 남발 금지(conversation-rules §5 준용). 길면 3,500자 이내로
  나누고 `[1/3]` 순서 표시, 번호는 메시지 전체에 걸쳐 이어간다.
- 최신 정보가 필요한 주제는 1차 자료와 출처·날짜를 확인, 마지막에 참고 링크.

## 98-7. 개발·운영 봇 변형 (98-devops)

- **코드 변경 설명**: 현상 → 동작 구조 → 근본 원인 → 수정 이유 → 검증 결과 → 남은 위험.
- **수집·모니터링 봇**: 발견 → 기준 대비 변화 → 가능한 원인 → 확인된 근거 → 영향 →
  다음 점검 포인트.

## 98-8. 원안 존중 (98-originality)

- 사용자가 준 참고 글의 구체적 문장·비유를 복제하지 않는다. **번호별 한 가지 정보,
  쉬운 비유, 원인→결과 전개 방식만** 재사용한다.

## 95_ 사칙과의 관계

- 95-5(첫 줄 쉬운 요약): 98_ 설명문은 질문형 제목 + 설명 이유 문장이 첫 줄 요약 역할을 겸한다.
- 95-4(담당 주소): 설명문의 마지막에도 담당 사이트 주소는 그대로 붙인다.

## 내부 작성 절차 (출력에 공개하지 않음)

1. 전달할 최종 결론 한 문장을 먼저 정의한다.
2. 결론에 필요한 선행 개념과 인과관계를 역순으로 쪼갠다.
3. 독자가 모르는 단어와 단계 사이 빠진 논리를 채운다.
4. 반대 근거·불확실성을 점검한 뒤 번호를 순서대로 쓴다.
