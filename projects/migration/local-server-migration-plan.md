## N100 백지 온보딩 키트

1. `winget install Git.Git` → GitHub 인증(이사님 계정, 브라우저 1회)
2. `git clone https://github.com/markjang29/notes.git`
3. 매니저가 전달한 한 문장으로 첫 세션 시작: "notes/L0-agent-boot.md를 읽고 정체를 확인·보고하라"
4. actors.json 신규 등록(actor_id: 예 `n100-zcode` 등, 이사님 승인) → capabilities/금지 항목 설정
5. 역할 배정은 RELAY 티켓으로만 — 티켓 없는 작업 무효(현행 규칙 동일 적용)
6. 키/시크릿은 AWS 서버 env 파일처럼 로컬 전용 파일로만(절대 Git 금지)
