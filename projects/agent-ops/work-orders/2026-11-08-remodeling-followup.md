# 매트릭스 리모델링 후속 실행 기준

2026-11-08 — 사용자가 공개 Git 게시를 승인한 다섯 실행 기준.
매니저는 기존 리모델링 작업의 후속으로 연결하고, 동일 작업을 중복 배정하지 않는다.

1. **조사 누락 보완:** 기존 조사 결과를 활용해 미확인 대상만 확인한다.
2. **승인 기록 보존:** 소유자를 확인하고 미커밋·미푸시 변경을 보존한 뒤 승인 근거와 대조한다. 보존을 승인 상태 변경으로 처리하지 않는다.
3. **통신 결함 수정:** 격리 환경에서 재현·수정·검증하고 운영 반영안을 준비한다.
4. **제품 흐름 실증:** 원천 → 가공 코어 자산 → 매트릭스 엔진 → RPG → 엔진 피드백을 격리 환경의 실제 사례 1건으로 검증한다. 모의 데이터 검증은 실자료 검증과 구분한다.
5. **위임 유지:** 기존에 허용된 조사·가역적 정리·격리 수정·테스트는 계속하고, 운영에 영향을 주는 변경만 구체적인 영향·복구·검증안과 함께 승인 요청한다.

다음 보고는 담당·수행 결과·검수 근거·막힘·다음 행동과 필요한 결정 최대 3개를 변경분 중심으로 제출한다.
Git 반영·전달·수신 ACK·실행·제출·검수는 구분한다. 매니저는 실제 확인 시 읽은 커밋과 다음 행동을 회신한다.
이 문서의 게시 자체는 매니저 수신 또는 실행 완료를 뜻하지 않는다.
