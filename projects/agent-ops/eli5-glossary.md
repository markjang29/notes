# ELI5 고정 비유 사전

> 이유: 이사님 09-06 "어떻게하면 니가 설명을 계속 내가 알아듣기 편하게할까?" —
> eli5 요청이 반복되는 건 eli5가 예외 취급이라서. **eli5를 기본값**으로 바꾸고,
> 같은 개념은 항상 같은 비유를 쓴다(봇마다 비유가 바뀌면 이사님은 매번 다시 배운다).
> 전 봇 규칙: 첫 줄 결론 → 비유 먼저·실명 괄호 → 숫자 3개 이하 → 한 보고 한 주제.

## 고정 비유 대응표

- **테일스케일(tailnet)** = 우리 기계들만 다니는 가족 전용 복도. 밖에서 안 보임.
- **엣지 서버(edge)** = 현관의 문지기. 밖 문을 열어주고, 진짜 일은 안쪽 집이 한다.
- **홈 리눅스(duradev, N100 1번)** = 본진. 실서빙을 맡을 집.
- **GLM 프록시** = 통역 데스크. AI 모델과 대화할 때 문 앞에서 말을 바꿔주는 창구.
- **하네스(harness)** = 일하는 방식 그 자체. "뭘 시킬지·어디까지 만지고·무엇으로 검수할지"가 적힌 작업 지시서.
- **Task Contract(7필드)** = 작업 지시서의 필수 칸 7개. 이게 없으면 일 시키지 않는다.
- **게이트(gate)** = 검문소. 빌드·테스트·규칙 위반을 통과 못 하면 다음으로 못 나감.
- **Evaluator/감사봇** = 검수자. 일한 봇과 다른 눈으로 다시 보는 사람.
- **git worktree** = 복사본 작업실. 서로 일이 섞이지 않게 방을 하나 더 빌리는 것.
- **Strangler(스트랭글러)** = 이사하면서 방 하나씩 바꾸기. 온집을 하루에 뜯지 않는다.
- **Modulith** = 방마다 용도 정하기. 거실에 부엌을 안 놓는 것.
- **provenance(6필드)** = 재료 출처 스티커. 이 데이터 어디서 왔는지 안 적으면 통과 못 함.
- **AGENTS.md / CLAUDE.md** = 냉장고 문 포스트잇. 항상 눈앞에 있어서 AI가 꺼내 보지 않아도 보인다.
- **스킬(skill)** = 레시피 책장. 필요할 때 꺼내는 물건이라, 꺼내라고 안 하면 안 봄(실측 56% 미호출).
- **POLICY_SHA** = 규칙책 판본 번호. 모든 보고에 "몇 판 규칙으로 일했는지" 도장.
- **활성 공지** = 게시판에 못 박은 공지. 내리기 전까지 모든 봇이 매번 읽는 것.
- **인벤토리(inventory)** = 집안 짐 목록 잡기. 이사(이관) 전에 뭐가 있는지 적는 것.
- **동결(freeze)** = 새 짐 사기 잠깐 멈추기. 이사하는 동안 짐이 불면 영원히 못 옮김.
- **OOM** = 방이 꽉 차서 사람이 쓰러짐. 스왑은 바닥에 깔는 임시 매트리스.

## 운영 규칙

1. 새 개념이 자주 나오면 이 표에 추가한다(매니저가 원장 갱신).
2. 보고에서 이 표의 비유를 썼다면 괄호 실명은 첫 등장 때만.
3. 이사님이 "자세히"라고 하면 비유 없는 기술 상세로 전환한다.
