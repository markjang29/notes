## 4. 모바일 최적화 + Vercel React 로드맵 (2단계)

- **1단계(AWS 8025, 당장)**: 반응형 단일 컬럼·카드 스택·터치타깃 44px·SVG 차트. 데이터 API를
  JSON으로도 노출(`/api/*`) — 이후 프론트 교체 대비
- **2단계(Vercel React)**: 프론트만 React(PWA)로 Vercel 배포, 데이터는 AWS API 사용.
  **react-best-practices skill 기반으로 모바일 최적화·리팩토링 검토 사이클** 진행.
  과제: CORS·열람 토큰·업데이트 배포 흐름
- **skill 배치 완료/계획**: AWS claude 전 봇 공용 `~/.claude/skills/react-best-practices/`
  **설치 완료(실측 — 세션 로딩 확인)**. 원격 사이트(firewin·gmwin·gmlnx)는 온보딩 문서·입장
  키트에 설치 절차 추가(각 사이트 claude 위주). zcode 엔진은 skill 미지원 → 제외
