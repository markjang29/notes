# QA-4 뮤테이션 시범 — 요구정의 v1 (GOV#29 하위, 2026-11-03)

> 정본 계획: qa-pipeline-execution-v1.md §1 Hardener 단계·§3 4번.
> 지위: 요구정의 완료. 시범 실행은 **대형 티켓(kind:코드+대형) 발생 시** 착수.

## 1. 적용 조건
- 태그 `kind:코드` + `대형` 동시 티켓만. 일반 코드 티켓은 뮤테이션 면제.
- 전제: 해당 티켓의 커버리지 80%+ 달성 후(After = Cleaner 단계 통과).

## 2. 도구
- 파이썬: `mutmut` (~/.venvs/novelweb — 시범 착수 시 설치)
- 자바: `PIT` (Maven/Gradle 프로젝트 — 해당 시점에 결정)

## 3. 게이트 수치
- 뮤테이션 점수 70%+ 통과. 미달 시 '구현' 복귀·보강 사유 1줄 기록.

## 4. 시범 절차 (대형 티켓 1건)
1. mutmut run --paths-to-mutate <대상 모듈> (타임아웃 상한 30분 — 비용 보호)
2. 점수 실측 → 티켓 꼬리에 `뮤테이션 점수 n% (mutmut)` 기록
3. 결과 회의방 보고 → 이사님 판정 후 전사 확대 여부 결정

## 5. 비용 상한
- 뮤테이션 1회 실행 ≤ 30분 CPU. 초과 시 대상 모듈 분할 후 재측정.
