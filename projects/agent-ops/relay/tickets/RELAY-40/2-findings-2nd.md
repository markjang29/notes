# [조사 2차] 상태창 2.2v 심층 + 실험 글 — 발견과 아이디어
- jira: RELAY-40 / 2026-08-23

## 파티 상태창 2.2v (자료 게시글 심층)
- **4패널 토글**: STAT(풀 스탯 STR~CHA) / PARTY(동료만) / CP(종합 전투력 한 줄) / DICE(주사위 판정 중심).
  "수치가 세계관을 바꾼다"(근력 1포인트=강철 문 파괴) — 스탯의 게임적 의미 부여.
- **보스 HP 바+고유 스킬+난이도**, 선택지→주사위 판정→동료 연계(실패=엄호/성공=연계공격).
  선택지·판정 마커 문법 존재: `[번호|행동자|행동|유형|"대사"]{성공|보조|d50+4 vs 15|"대사"}`.
- **보조 모델 위임** — 상태창·전투 연산은 보조 AI, 메인 모델은 서사 전용(2.1v→2.2v 핵심 개선).
- **테마 스킨 4종**: Classic(슬레이트+민트) / Paper(양장지+골드) / Jade(비취) / Sanctus(잉크블랙+실버).
- GM 설정 시트 = 전 기능 토글.

## '하루를 RPG 게임 퀘스트로' (로어북)
- 일상을 RPG 퀘스트 UI로: HP/MP 바(■■■□□)·메인/서브/히든 퀘스트·획득 아이템·전투 로그
  (Critical Hit! 9999 데미지)·업적·다음 퀘스트 난이도(★).
- 핵심 기법: RisuAI **{{random::A::B::C}} 매크로로 판정 무작위화** + SVG/CSS UI.
- 원칙: "캐릭터 성격에 맞는 스탯"(소심=회피율↑) — 성격→스탯 매핑.

## 'RPGM 스타일' 실플레이 로그
- 클래식 RPG 구조가 채팅에서 실제 돌아감: 마을 아침 → 퀘스트 게시판(슬라임 퇴치 500G ★☆☆☆☆) →
  무구점/약방 상점 메뉴·가격 → **소지금 추적(300G→100G→20G)** → 아이템 획득 메시지 → NPC 복선.
- 유저가 원하는 건 "알만툴의 마을-상점-퀘스트 루프"의 채팅 재현.

## 커뮤니티 장르 신호 (게시글 목록)
- "영지 발전물이 되어버렸어"(영지경영), "하드 퀘스트 줘봐", "F급 넣으려고 발악"(헌터 성장물),
  현대던전시뮬 — 헌터/던전/영지/성장 = 검증 장르.

## 종합 아이디어 (메이킹 툴 반영)
1. UI 자산에 **테마 스킨 변수**(Classic/Paper/Jade/Sanctus 계열) — 한 UI에 팔레트 변형 세트.
2. **판정 마커 문법**은 매트릭스(텍스트 게임) 영역 — RPG 메이킹 툴은 결과물(전투 로그 패널·주사위
   아이콘·HP바)을 자산으로 공급하는 역할.
3. 상점/소지금/퀘스트보드 UI = 알만툴 루프 재현용 핵심 UI 자산 목록에 추가.
4. 성격→스탯/회피율 매핑 원칙 = 캐릭터 자산 메타에 "성격 태그" 필드 추가 근거.
