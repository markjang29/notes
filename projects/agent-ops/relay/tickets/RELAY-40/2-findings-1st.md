## 플래그십 사례 분석

### 1) TRPG MASTER v1.5.4 (다운로드 8700+, 파일 577MB!)
채팅 TRPG의 완성형. 릴리즈 노트(v1.4.x~1.5.4)에서 검증된 설계:
- **캐릭터 시트+장비/스킬 파싱**, 직업별 복장(bard/ranger/warlock), **감정 태그 초상화**
  (neutral 초상 보장 + 감정별 컷 분리), 포즈 태그.
- **전투 카드+주사위 패널+파티 상태창** — HP/MP/적 HP/EXP/보상, 처치·보물·시나리오 클리어 →
  아이템/스킬북이 **공용 가방 상태**에 저장.
- **세션 저장/불러오기 코드** — 진행 상태를 코드 한 줄로 세이브/복원.
- **메인 LLM/보조 모델 분업** — 메인은 런타임 마커(의도·적·상태), 보조는 주사위·전투·추천
  리드 패널. 프롬프트 경계 계약 설계.
- **xNAI(이미지 생성) 가이드 내장** — 채팅 게임에 NAI 이미지 프롬프트까지 통합.
- Risu 트리거·Lua·regex UI, 한/영/일 다국어. 577MB = 이미지 자산을 모듈에 내장(우리는 분리+SHA).

### 2) 고블린기지(반복형 던전) 로어북
- **입장 시 난이도 스캔**(헌터 마나 밀도) → Normal/Hard/Master 자동 — 적응형 난이도.
- 독립 공간 생성+입장 시 리셋(반복 콘텐츠), 난이도별 테마("Sweep"/"Tactics")·환경 진화
  (나무 요새→강철 벙커+독수령)·몬스터 교체(고블린→호브고블린)·보스 패턴.
- 현대 헌터 특구 세계관(웹소설 문법) — 한국 시장 검증 장르.

### 3) JRPG식 전투 로그 (만화/쯔꾸르 스타일 계열)
- LLM 출력을 **html/css로 게임 UI 렌더링**(750px, JS 제외) — 행동 인물/행동/데미지/버프/대사/상황.
- "채팅창 안에 게임 화면을 그린다" — 채팅 RPG UI 기법의 원형. 상태창 UI 자산 다수
  (파티 상태창 2.1→2.2v 버전 관리, 만화 스타일, 미연시 스타일, 뮈토스 UI v1.0 등).

## 메이킹 툴(RELAY-36) 반영 아이디어 7가지
1. **UI 자산 수요 증명** — 상태창·전투 로그·주사위 패널이 채팅 RPG UI 3종 세트 → 워크벤치 UI/EFX
   유형의 최우선 제작 대상 근거.
2. **감정 태그 초상화** — 캐릭터 자산을 "neutral 기본 + 감정별 변형 세트"로 설계.
   우리 눈 인터페이스(공격 분류 시선)와 직결되는 검증 패턴.
3. **유저 검증 NAI 프롬프트 흡수** — TRPG MASTER의 xNAI 가이드 등 실전 프롬프트를 워크벤치
   프롬프트 정본(템플릿) 후보로.
4. **레시피=세이브 코드** — 상황판의 조합(전장+캐릭+이펙트)을 코드 한 줄 공유/복원 가능하게.
5. **메인/보조 LLM 분업 마커** — 참모(예측)×지휘관(판단) 구도와 동일 사상. 프롬프트 경계 계약 참고.
6. **적응형 난이도(스캔→진화)** — 전투 관찰 시스템 기반 전장 진화 설계의 원형.
7. **채팅창 UI 렌더링** — 모바일 목업 미리보기(부록2 아이디어3)의 실현 기법(제약: JS 없이 html/css).
