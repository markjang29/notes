## 3. react-best-practices 적용 (설계·구현·검수 전 단계 — 원장 지시)

- `async-parallel` — 허브 초기화 시 모듈 상태·자산 카탈로그를 Promise.all 병렬 조회
- `bundle-dynamic-imports` — Godot WASM 런처는 동적 import(허브 번들에서 분리)
- `rerender-memo` + `rerender-no-inline-components` — 카드/그리드 컴포넌트 분리·memo
- `rendering-conditional-render` — 삼항식, 상태 Pill·에러 뷰
- `rendering-content-visibility` — 모듈 카드 롱리스트에 content-visibility
- `js-set-map-lookups` — 모듈 상태 인덱싱. 시행 결과는 보고에 규칙명으로 명시.
