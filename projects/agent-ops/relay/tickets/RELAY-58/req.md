## 3단계 접근 (매니저 제안)

1. **0단계(즉시, 개발 거의 0)** — 각 단말 크롬에서 기존 사이트 URL을 열고 "홈 화면에 추가"
   (PWA 풀스크린). 단말마다 URL 하나 지정으로 끝. 단말 번호 스티커(D1~D10).
2. **1단계(소규모 개발)** — 단말 등록 페이지: 단말가 스스로 등록하면 서버가 단말→뷰 매핑을
   원격 지정·변경(단말 재세팅 불필요). 풀스크린 전용 렌즈 뷰(auto-refresh). P/C·R/N 번호 체계와
   연결("D7 렌즈 = R012 카드").
3. **2단계(이후)** — VR: 웹 기반이므로 WebXR 경로로 자연 확장. 단말이 그대로 VR 뷰어 소스가 됨.
