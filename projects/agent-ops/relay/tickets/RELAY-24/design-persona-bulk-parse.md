- 입력 확장: 지금까지 risum 단독 대상이었던 것을 **포스트 단위 번들링**으로 확장 —

  projection은 기존 `risu-native-projection-v1` 형식. 검증은 `checks/validate_records.py`
  (contract 오류 0 유지, 실패 시 해당 포스트만 fail 리스트로 — 전체 중단 없음).
