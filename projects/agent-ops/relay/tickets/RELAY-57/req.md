# [req] 전 사이트 페이지·컴포넌트 고유번호 (P/C) — 디버그 모드 표시
- jira: RELAY-57

  "일단 모든 페이지 상단에 간단한 고유 숫자로 식별하게 만들어줘 p1 p2 이렇게
  그리고 그 페이지 중간중간 개체들에도 저런 간단한 숫자 c1 c3 ? 를 부여해서 의사소통을 편하게 하자
  매번 오류 지적하기 힘드니까 짧은 고유번호를 항상 추가하자
  이건 디버그 모드일 때만 보이도록 개발해줘"
- 발화자/채널/일시: 이사님(director) → 매니저 Telegram, 2026-08-26 수령

## 목적

이사님의 오류 지적·요청을 "8016 P1 C3" 한 단어로 받을 수 있게 전 사이트 UI에 안정 식별자를
식는다. 평상 화면은 변화 없음.

## 규격 (매니저 초안 — 구현 담당 공통 준수)

1. 페이지 번호 `Pn`: 사이트(포트)별로 자기 페이지에 P1, P2… 부여. 대화 시 `8018 P2` 형태로
   포트+페이지로 지칭. 페이지 상단(헤더 근처)에 표시.
2. 컴포넌트 번호 `Cn`: 페이지 내 의사소통 대상 단위(카드, 버튼 그룹, 폼, 리스트, 모달)에
   C1, C2… 부여. DOM에 `data-cid="C3"` 속성 + 좌상단 작은 라벨. 동적 반복 요소는 그룹 레벨에
   번호(개별 아이템은 그룹 번호 + 순번 표기 가능).
3. 디버그 모드: URL 파라미터 `?debug=1`(또는 사이트별 등가 토글)일 때만 P/C 라벨 렌더.
   기본 화면·기존 기능 일절 변경 금지. 세션 저장 없이 URL만으로 동작 권장.
4. 번호 안정성: 한번 부여한 번호는 재배열로 바꾸지 않는다(번호-요소 매핑은 코드 상수로).
5. 스타일: 라벨은 최소 크기·반투명 배지, 클릭·레이아웃 영향 0.
