## 제안 원칙: 완료 선언 = 실행 증거

**"구현했다"의 정의: 해당 기능을 실제 사용자 경로로 실행하고 그 증거를 기록했을 때만 완료라고 한다.**

1. **기능 단위 검수** — 존재하는 모든 상호작용 기능(버튼·탭·링크·생성·편집 등)은 각각 1회 이상 실제 실행. "있다"가 아니라 "돌려봤다"가 기준.
2. **정적 확인은 완료 근거가 아님** — 문법검사·컴파일·응답코드 200은 보조 수단. 단독으로 완료 선언 금지.
3. **기능 추가 = 테스트 추가** — 새 기능을 넣으면 배포검사 스크립트에 해당 흐름이 같이 추가되어야 완료. (미추가 = 미완료)
4. **증거 기록** — 실행 결과(출력·스크린샷·헤드리스 로그)를 5-impl 템플릿 "테스트 결과"에 첨부. 이사님이 최초 발견자가 되면 그 기능은 검수 실패로 간주.
