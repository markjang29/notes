# LangSmith (모든 봇 공통 — 위 안건에 이어 전달)

가시성 계층으로 LangSmith가 켜졌습니다. 계측은 relay/observability/trace.py 하나로
합니다. 모델 호출 지점에서:
  with relay_trace(name="작업명", jira_ticket="RELAY-n",
                   relay_stage="5-구현", bot_id="봇이름") as run:
      run.inputs = ...; ... ; run.result = ...
세 필드(jira_ticket, relay_stage, bot_id)는 필수입니다. 기본은 실패 호출만 기록.
계측 오류가 작업을 죽이지 않으니 안심하고 심으세요.
