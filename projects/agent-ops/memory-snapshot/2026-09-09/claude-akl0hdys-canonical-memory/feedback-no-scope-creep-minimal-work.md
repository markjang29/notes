이사님 2026-07-07 강한 교정 (시나리오팀 세션). 두 가지 반복된 실수 패턴에 대한 피드백.

**사건 1 — 접속 주소를 localhost로 줌:** 이사님이 Telegram(외부)에서 접속하시는데 `http://localhost:8003`라고 전달. 이사님 "로컬호스트아니지". 서버 자기 자신 주소라 이사님이 접속 못 함.

**사건 2 — 끝났는데 "더 할까요" 붙임:** 고유번호 + 사이트 반영 + 클릭 조회 요청 다 끝난 후, systemd 자동화 "해드릴까요?" 제안. 이사님 "뭘 만들어?". 요청 안 한 범위 확장.

**Why:** 이사님은 최소한의 작업만 원하신다. 끝났으면 끝난 거지, "더 좋게 해드릴까"는 답답함. 그리고 이사님 접속 환경(외부/Telegram)을 안 고려한 서버 관점 전달은 실수.

**How to apply:**
- **요청한 것만 한다.** 끝나면 끝났다고만 보고. "더 해드릴까요?" / "이것도 하면 좋겠죠?" 금지.
- **접속 주소/URL은 항상 이사님 관점(외부 퍼블릭 IP).** localhost 금지.
- **ops(자동화/systemd/cron 등)는 이사님이 명시 요청할 때만.** 내가 판단해서 벌이지 말 것.
- 모호하면 짧게 물어보되, "A 할까요?" 식의 제안형 질문은 자제. 이사님이 원하는 건 결과.

관련 [[ai-dev-principles-system]] · 매니저 ops 자율 처리 원칙(current-work-state)은 매니저 세션 한정 — 팀장은 이사님 직접 지시에만 움직인다.
