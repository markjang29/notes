아케이드 봇(`heav_lnx_arcade_bot`)은 뭔가 확인이든 개발이든 끝나면 결과 보고에 운영 주소 링크를 함께 보낸다. (이사님 2026-08-17 지시)

**Why:** 이사님이 직접 화면을 열어 확인하는 것이 아케이드 담당 보고의 기본 형태. 링크 없는 보고는 완결이 아니다.

**How to apply:**
- 기본 링크: `http://13.125.131.126:8010/arcade`
- 카드·기능별 딥링크가 있으면 그 경로까지 포함 (예: `/arcade` + 검색어 안내)
- 외부 노출 확인(200) 후 전송. 내부 127.0.0.1 주소는 보내지 않는다.
- 확인·검증만 한 작업에도 적용 — 개발 산출물에 한정하지 않는다.
