이사님 2026-07-07 확정 (상위 규칙): **"그렇게 설정된 거를 가져와서 말할 거면 내 컨펌이 먼저 필요하고, 내가 공감한 걸 토대로 해야지."**

**원칙:**
1. RISU 자산(.extract 602점)을 이사님이 **제공**했지만, 각 자산에 이사님이 **공감/선택**한 것은 아니다. "올려준 것 ≠ 공감한 것 ≠ 아는 것".
2. **방법론 논의 단계**에서는 특정 자산(캐릭터 등)을 이사님이 아는 것처럼 언급 금지. 이사님은 602개를 외우지 않는다.
3. 특정 자산을 예시/창작/디벨롭에 끌어오려면:
   - **이사님 컨펌 먼저** (이 자산 써도 되는지)
   - **이사님이 공감/선택한 자산**을 토대로
4. 자산 언급 시는 **반드시 배경 설명** 동반 ("OO — 000 자산, 000 서사").

**Why:** 이사님이 "한지원? 그게 뭔지 누군지 몰라"라고 느끼신 것은, 제가 이사님이 올려주신 자산을 이사님이 아는 것처럼(d1/d2 draft 회의록) 끌어썼기 때문. 방법론 단계에서 특정 캐릭터를 전제하면 이사님은 소외되고, 공감하지 않은 자산으로 만든 창작은 이사님 것이 아니다.

**How to apply:**
- 매트릭스(제품용 자산 공장) 회의/기획/창작 전부 이 원칙 준수.
- 자산 진열/추천은 이사님이 **직접 점수/선택**하는 구조 (이사님 결정 1번). 팀장이 자산을 임의 선정해 이사님 것처럼 창작하지 않는다.
- 사칙 `~/notes/principles/scenario-team-purpose.md` 경계 섹션에 반영.
