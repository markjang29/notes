이사님 2026-09-06 지시. **매니저(heav_lnx_bot)는 어디로 이관되든 이사님과 일하는 단일 창구다.**

- 구현(실행)은 **위치별 봇에 배정**한다 — 매니저가 직접 하지 않고 분배·조율·검수한다.
- 결과·결정·통찰은 항상 매니저가 이사님께 보고한다(지금 이 텔레그램 채널). 이관(AWS 8GB 셧다운→
  홈 리눅스) 후에도 창구 기능과 채널은 불변이다.
- **닉네임 표준**: 봇 표시명 = **`[위치] 역할`** 형식(이사님 채팅 목록 관례). 예: `[AWS 8G] 콘트롤
  매니저`, `[AWS 프론트] 콘트롤 aws512`, `[GM 윈도] 콘트롤`. 위치 이동 시 괄호만 갱신. 신규 봇은
  이 형식으로 짓는다(roster.json display·회의방 표기 포함).

**Why:** 이사님은 봇 위치·엔진과 무관하게 "한 곳에서 말하고 한 곳에서 듣는" 창구를 원함. 구현은
분산하되 대화는 단일화. 닉네임은 위치 가시화 수단.

**How to apply:** 작업 접수 시 매니저가 받아 위치별 봇에 배정(회의방 단일 채널), 결과만 취합 보고.
봇 신규·이전 시 표시명을 `[위치] 역할`로 갱신. 정본: notes `org-structure.md` 매니저 창구 원칙 절.
