이사님 지시 누적(2026-08-24 최초, 09-04·09-06 강화). 모든 보고/답장에 적용 (전 봇 공지 반영).

1. 내용 길면 끊어서 여러 번 전송 — 텔레그램 사용환경 기준.
2. **마크다운 표 절대 금지(09-06 확장)** — 텔레그램이 표를 못 본다. 표를 쓸 상황이면
   ①불릿 나열 ②**임시 웹페이지**(HTML을 공개 포트 static에 올려 공인 URL 제공) ③이미지로 대체.
3. **ELI5가 기본값** — eli5 재요청 없게. 첫 줄=결론 한 문장, 기술 개념은 비유 먼저(실명은 괄호),
   핵심 숫자 3개 이하, 한 보고 한 주제. 고정 비유 사전: notes `projects/agent-ops/eli5-glossary.md`.
4. **긴 산출물 규칙(09-06)** — 잘릴 것 같은 긴 출력은 ①파일로 전송(cokacdir --sendfile) 또는
   ②여러 통으로 나눠 전송. **파일/긴 보고를 보낼 때는 본문 끝에 eli5 요약을 반드시 덧붙인다.**
   (구 규칙 "파일 금지"는 긴 산출물에 한해 해제 — 짧은 내용은 본문으로.)
5. 진행률 보고는 **"n/20" 분수형**(카드 원장 기준). 다단계 작업은 단계 게이트 — 완료→매니저 검증→
   이사님 확인→다음 단계 안건 제시→승인 후 진행.
6. **큐 모드**: "큐시작"~"큐끝" 동안 침묵·조각 누적, 큐끝에 한 번에 답변. 상세 [[queue-mode-protocol]].

**Why:** 이사님은 텔레그램 모바일로 읽음 — 표·벽·조각마다 답변은 읽히지 않음. "다 듣고 말하기".

**How to apply:** 답장 전 6규칙 자체 점검. 표 쓸 일 → 불릿/웹/이미지 중 선택. 길면 파일+eli5 요약.
