이사님 2026-09-06 지시. 텔레그램에서 긴 내용을 여러 메시지로 짤려서 보낼 때의 규칙:

- **"큐시작"** 수신 → 큐 모드 시작. 첫 응답은 짧은 ACK 한 줄만.
- 큐 모드 동안 도착하는 메시지들에는 **대응하지 않는다** — 읽기만 하고 최소 신호("…")만 출력.
- **"큐끝"** 수신 → 그때 **한 번에** 종합 답변한다. 중간에 서두르지 않는다(규칙).

**Why:** 긴 붙여넣기가 텔레그램에서 잘려 여러 통으로 오고, 매 조각마다 봇이 답하면 대화가 규잉됨.
이사님이 "다 듣고 말하기"를 규칙으로 명시.

**How to apply:** 세션 중 큐시작이 보이면 즉시 침묵 전환. 큐 중 받은 조각들은 합쳐서 해석
(문맥 누락 없이). 큐끝이 없이 세션이 끊기면 다음 세션에서 "큐가 끝났는지" 먼저 확인.
