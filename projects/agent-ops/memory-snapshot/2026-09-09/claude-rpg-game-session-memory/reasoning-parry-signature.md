2026-07-02 회의에서 rpg_game **전투 시그니처(정체성 동사)** 확정. 이사님이 CIPHER/LUMEN/RUMOR 후보 대신 독자 방향 제시 → 팀장 정리 → Codex 검증(수정 채택 권고) → 이사님이 "오토배틀러화 방지=패막"으로 핵심 리스크 해결하며 콜.

**시그니처 한 줄**: 캐릭터(참모)는 불완전한 추론 보고서로 작전안을 내놓고, 플레이어(지휘관)는 그것을 골라·고치고, 결정적 순간에는 직접 **패링** 입력으로 확률을 뒤집는다.

**삼각 구도:**
- **참모**(캐릭터/AI): 불완전한 추론 보고서(전제·근거·위험·확신도). 정답 아님 — 편향·누락 존재. 레벨 오를수록 사고 정교(숫자 스탯 성장이 아니라 "사고의 질"로 성장 시각화).
- **지휘관**(플레이어): 작전안 2~3개 중 선택/수정(전제 토글·우선순위·위험 허용도). 매 턴 전술 입력.
- **손**(플레이어): 결정적 순간 패링 입력으로 기대값 뒤집기. 적 공격 임밋 시마다 손 개입 → 오토배틀러화 구조적 차단.

**핵심 문장**: 캐릭터는 "반격 위험 30%"까지 계산하지만, 그 30%를 **0%로 만드는 건 플레이어 패링 손맛**.

**캐릭터 정체성**: "생각은 천재, 패션은 잼병인 AI". 지능(추론)=레벨/학습 축, 룩(색/코스튬)=걷기→색 포인트 축(`07`과 정합). 두 축이 분리. ⚠ ~~"걷기→전투력 0기여" 불변원칙~~ → **2026-07-03 `09` Walk-to-Play로 전복 폐기**(걷기→전투 윈도우 허용). 단 **"걷기→사고(추론) 분리"는 09에서도 유지** — 지능축은 걷기와 무관.

**Codex 채택 조건 3 (모두 수용):**
1. PvP 추론/토큰/정보 완전 정규화(랭크 양측 동일 경기용 두뇌, 보너스 0기여).
2. 캐릭터 성장 추론은 PvE·스토리 중심(PvP는 평탄). 고레벨 사고는 캠페인에서 빛남.
3. 보고서 = 짧은 칩 UI(한 줄 결론 + 근거 칩 ≤3 + 접기). "정답 제시" ❌ / "편향 있는 작전안 교정" ✅.
- 우회 T2W 금지: 걷기가 학습속도·토큰회복·고급해금 가加速하면 모두 역류 → 금지. 토큰은 매치 내 동등 지급.

**PvP "진검승부·비김"**: WEGO 동시명령 + 목표 기반 점수 + 턴 제한(6~8턴)으로 비김이 구조적으로 발생. 동일 정보라도 `보수/기습/거점/교환` 목표 선택 + 패링 실력이 승패 분리축. 랜덤 명중/치명 최소화.

**Why:** 이사님 직관이 시대정신(2025-26 LLM 추론 일상화)에 부합 + 이미 검증된 첫 모듈(parry/grid_parry)이 시그니처 핵심(오토배틀러화 차단)으로 재사용 → 자산 낭비 없이 정체성 동사 확립. CIPHER 등은 이사님에게 "구체적 컨셉 안 와닿음"이라 폐기.

**How to apply:** 전투 설계 시 (1) 추론은 "편향 있는 작전안 제시"지 정답 아님, (2) 매 공격 타이밍에 플레이어 패막 개입 보장, (3) 걷기와 전투력(추론) 단절 유지. 다음 모듈 = `reasoning` × `grid_parry` 통합 프로토타입(B안). 세부 수치는 본편 조립 시점까지 보류.
