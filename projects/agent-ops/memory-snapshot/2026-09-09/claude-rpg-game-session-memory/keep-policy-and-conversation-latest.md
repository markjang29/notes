**Why:** 최신 결정(Reasoning-Parry 시그니처 확정 · manufacturing 폐기 · 첫 보스 한 판 체험 전환)이 RPG 정체성의 핵심인데, 구버전(2026-06-26 걷기×전술 초안, 폐기된 CIPHER/LUMEN/RUMOR 컨셉)이 문서·산출물·대화에 섞여 있으면 정체성이 흐려지고 혼란이 발생한다. 실제 사례 — 8004 웹페이지를 06 컨셉 수렴안으로 만들었다가 이사님이 "한참 전 의사결정 같다"고 지적 (2026-07-07).

**How to apply:**
- 산출물·대화·정책 문서를 작성·갱신할 때, 항상 가장 최근의 확정 결정(현재 = `08-reasoning-parry-signature.md` 이후)을 기준으로 삼는다.
- 구버전 문서가 최신과 모순되면 (예: `IDEATION.md` 상단이 여전히 CIPHER/LUMEN/RUMOR를 "후보"로 소개), 최신 기준으로 다듬거나 최소한 헤더에 상태(폐기/최신 링크)를 표시한다.
- 폐기된 컨셉·배정(manufacturing-coverup-B01 등)을 현행인 것처럼 전제하지 않는다.
