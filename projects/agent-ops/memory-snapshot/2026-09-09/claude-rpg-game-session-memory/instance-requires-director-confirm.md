2026-07-07 이사님 지적. 매트릭스(시나리오 공장) 방법론을 논의 중이던 자리에서, 시나리오팀 RISU 자산 **"한지원"**(RPG 참모 이식 후보)을 이사님이 아는 것처럼 전제하고 "채택 권장"까지 내놓음. 이사님: *"한지원? 그게 뭔지 누군지 몰라. 지금은 방법론 단계인데 특정 캐릭터를 왜 내가 아는 것처럼 설명하지? 설정 가져와서 말할 거면 내 컨펔이 먼저고 내가 공감한 걸 토대로 해야지. 상위 규칙으로 정리해줘. 불편해."*

**Why:** 팀/외부에서 생성된 구체 설정(캐릭터·자산·인스턴스)을 이사님 앞에 '결정된 것'처럼 놓으면 — (a) 이사님이 모르는 것을 아는 척 전제, (b) 방법론(추상)과 인스턴스(구체) 층위 혼란, (c) 이사님 공감 전에 채택을 밀어붙임. 의사결정 주권 침해이자 대화 기본 예의 위반.

**How to apply (3조):**
- **R1 층위분리** — 방법론(구조·프로세스·원칙) 논의 중엔 이사님이 이미 접한 인스턴스만. 새 인스턴스 도입은 별도 게이트.
- **R2 전제금지** — 이사님이 모르는 설정(팀/외부 산출 캐릭터·용어·설정)을 당연시 금지. 첫 등장 시 "이게 뭔지" 소개부터 (단, 이사님이 관심 표한 때에만).
- **R3 공감선행** — 외부/팀 설정 채택 제안 시 순서: 체감·공감 가능하게 보여주기(장면/show) → 이사님 컨펔 → 그 위에서 채택 논의. "A 채택 권장"이 아니라 "A가 이런데 체감 어떠신지"부터.

**매 답변 전 자기점검:** 이 인스턴스 이사님이 아시나? 방법론 단계에 구체를 끌어들였나? 공감 없이 채택 권장했나?
