2026-07-09 이사님 연속 아이디에이션 수렴 → **방향 GO**. repo: `ideation/11-advisor-score-system.md`.

**한 줄**: 참모의 두뇌(사고 패턴·편향·전술)를 **"악보"**(텍스트 DSL)로 표현. 유저가 자기 GPT/Gemini에 사양서 올려 "작곡" → 게임에 적용. 악보 길이(사고 용량) = 참모 레벨(스킬랭크)에 비례 (마비노기 작곡 메타포).

**핵심 4:**
1. **레이어 분리(비용0)**: ① 참모 두뇌=게임 내 규칙 엔진(전투 중 LLM 0회) / ② 악보 작곡=유저 외부 AI 부담(서버 비용 사실상 0).
2. **걷기 2축**: 패링 윈도우(`09`) + **참모 수련 시간**(새). 통일 철학 "걷기=버틸 수 있는 시간(인내)". **기회(시간·횟수)는 주되 효율(한 번 효과)은 안 준다** — `08` "학습가속 금지" 정합. PvE 한정, PvP 정규화.
3. **DSL**: 도메인=전술의사결정(게임 고유, AI 훈련데이터 부재) / 형식=**제약(NEVER/MUST)+가중치(WEIGHT)+트랙(TRACK)**. 이사님 기준(화성학=너무 쉬움/수학=너무 어려움/프로그래밍=교육가능) 수렴. **AI가 "초안"은 짜주되 "완성"은 인간** — 난이도 4메커니즘(숨겨진 평가함수·도메인 고유개념·가중치균형·적대적환경). 명칭·문법·수치는 보류.
4. **세계관 프레임**: "참모가 만든 사고 언어를 지휘관이 배운다" = 프롬프트 엔지니어링 게임화.

**PvP**: "악보 무게 캡"(동일 음표 수까지만)으로 정규화. 긴 악보는 PvE·캠페인에서 빛남(`08` 조건1·2 정합). 승패는 목표선택+패링.

**시그니처 정합**: 삼각 구도(참모=악보×지휘관×패링) 유지. 본안이 `08`의 빈칸 "참모가 어떻게 성장하는가" = "유저가 악보 작곡·튜닝"으로 채움. "생각 천재·패션 잼병 AI" 정체성 진짜화.

**코딩교육 = 심화(본편 이후)** — 이사님 "설계에 왕전 박지 마, 심화로". DSL이 조건문/가중치/논리/모듈 내장이라 교육 부산물 가능하나, 본편 이전엔 DSL 본안이 교육 없이도 성립하도록 설계.

**리스크**: 유해 악보(검증/샌드박스) · 캡 우회(엄격 토큰 카운트) · DSL 밸런스(프로토타입 핵심 과제).
