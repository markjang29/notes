2026-06-26 회의에서 rpg_game 전술 RPG의 방향이 **수렴 확정**(사용자 1·2·3차 의견 + 팀장·서브에이전트·Codex 검증 거침).

**확정 컨셉(1안):**
- 코어: 걷기 → 입장재화(캡) → **동기화 전술 PvP** + **지역 PvE**(협동) + 캐릭터 성장·표현.
- **T2W 3겹 캡**: ① 입장권 로그캡 ② 하루 N판 ③ ~~걷기→전투력 0기여~~ → **★ 2026-07-03 전복 폐기**(아래 Walk-to-Play 참조). P2W 자원(대시/보호막/이동권) 판매 0은 유지.
- **로맨스**: 캐릭터 간 내러티브(A안). 유저×유저 위치 로맨스=불가.
- **남녀**: 진영·내러티브 분기(2세력 메커니즘 유지), 성별 무관. *(서사 "길 잇는 자 vs 길 끊는 자"는 2026-07-01 폐기 — 유치 판정. 백지 재검토.)*

**폐기(구조적 불가):** 비동기 위치 영토 PvP / 공성전 / 술래잡기(위치 기반) — T2W·인구밀도·공평성 결함. Codex 진단으로 판정.

**내러티브(α "잃어버린 길", 발자국 갈등 등)는 작가 검증 대기 — 메커니즘은 확정, 스토리는 위임.**

**Why:** 사용자가 "걷기 보상 확정 + P2W 차단"을 타협 불가 원칙으로 제시. 비판 디깅이 "비동기 위치 영토=구조적 불가"를 밝혀, 의도(걷기/PvP/P2W차단)는 살리고 메커니즘(위치 영토)은 교체하는 수렴에 도달.

**How to apply:** 다음 세션은 엔진 ADR(Godot 권장) + 시그니처(CIPHER/RUMOR) 결합 여부 + MVP 범위부터. 스토리 디테일은 확정 취급 금지(작가 검증 전).

**2026-07-03 — ★ 핵심 원칙 전복 (Walk-to-Play):**
이사님이 선행 원칙 "걷기→전투력 0기여"(`06` 캡③ · `08` §3·§4)를 **전복 폐기**하고 **Walk-to-Play**로 전환. 철학: *"돈 내는 놈이 강한 건 양심 없지만, 걸은 놈이 강한 건 정당하다."* 과금 P2W는 차단하되 **행동(걷기)=전투력**은 허용.
- **걷기 = 전투의 "버틸 수 있는 시간(인내)"**. 사무라이 진검승부 — 더 늦게까지 버티는 쪽이 심리적 우위, 결정적 순간 패링이 확률 역전.
- **PvE**: 걷기→윈도우 직결(기본 5.0초 + ~7000보/+0.7초, 캡 있음). 참모 추론은 레벨 축 단독 유지.
- **PvP**: 양측 동일 5.0초 정규화. 걷기는 **룩으로만**. 승부=순수 심리전+패링.
- **사고·시간 분리**(정체성 보존): 걷기→**시간(윈도우)** ✅ / 걷기→**사고(추론)** ❌ ("생각 천재" 유지).
- **자원 소비처 분기**: 플레이어가 룩 or 윈도우 선택(비전투 경로 허용).
- 문서 `ideation/09-walk-to-play-combat.md`, ADR `notes/decisions/2026-07-03-walk-to-play-principle-flip.md`. 다음 모듈 = `duel_advance`(진검승부 한 판).

> **주의(최신 위주)**: "걷기→전투력 0기여"를 현행 원칙으로 전제하면 안 됨. 현행은 Walk-to-Play. 단 P2W(과금→전투력) 차단은 여전히 유효. 관련 [[keep-policy-and-conversation-latest]].
