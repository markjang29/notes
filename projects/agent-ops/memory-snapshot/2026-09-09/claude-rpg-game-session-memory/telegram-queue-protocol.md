이사님 텔레그램 대화 규칙 (2026-09-06 지정):

1. **"큐시작"** 수신 → 여러 개 메시지가 이어지는 중(텔레그램 잘림·규잉 방지). **"큐끝"을 받기 전까지 절대 응답하지 않는다** (도중 반응·행동 금지).
2. **"큐끝"** 수신 → 그동안 들은 내용 전부 모아 **한 번에** 응답한다.
3. 답이 길어 잘릴 것 같으면 **파일로 만들어 전송**하거나 **메시지를 나눠서** 보낸다.
4. 응답 **끝에 ELI5(아주 쉬운 요약)** 를 덧붙인다.
5. **마크다운 표는 텔레그램에서 안 보임** → 표 대신 리스트/들여쓰기, 필요하면 임시 웹 페이지나 이미지(컨택트시트 등)로 보여준다.

**Why:** 이사님이 긴 지시를 여러 메시지로 연속 보낼 때 봇이 중간에 끼어들면 큐가 꼬이기 때문.
**How to apply:** "큐시작" 보이면 즉시 침묵 모드(도구 호출도 응답도 최소화), "큐끝"에서만 전체 처리. 2026-09-07 추가: 일을 시키면 `1/N` 식으로 단계·변경점을 보여주고 이사님 확인을 받은 뒤 다음 단계로 간다(진행보고 게이트). 전체 사칙은 [[edge-entrypoint-comms-progress-rules]]. 관련 [[instance-requires-director-confirm]].
